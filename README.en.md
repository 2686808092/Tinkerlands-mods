# Tinkerlands Mods

This repository contains only the Tinkerlands mod overview and distribution links. Source code, updates and packages are maintained in each mod's independent repository.

[简体中文](README.md) · **English**

| Mod | What it does | Download |
| --- | --- | --- |
| [Just Enough Items for Tinkerlands](https://github.com/2686808092/TinkerlandsJustEnoughItems/blob/main/docs/readme/README.en.md) | Search for items and look up their recipes, uses, and sources from the player inventory. | [Releases and downloads](https://github.com/2686808092/TinkerlandsJustEnoughItems/releases/latest) |
| [SiRan's Quality of Life Updates](https://github.com/2686808092/TinkerlandsQualityOfLife/blob/main/README.en.md) | Six independently configurable features: target reforge, fisherman furniture, simplified NPC gifting, map auto-explore, movable waypoints, and improved visibility. For Tinkerlands and Tinkerlands Playtest singleplayer. | [Releases and downloads](https://github.com/2686808092/TinkerlandsQualityOfLife/releases/tag/v1.0.0) |
| [ModList compatibility patch (original author: obfy)](https://github.com/2686808092/TinkerlandsModList) | Fix Playtest font errors while retaining the original mod manager. | [Download 1.4.1](https://github.com/2686808092/TinkerlandsModList/releases/latest) |

Place the ZIP file as-is in the `mods` folder of your Tinkerlands installation and restart the game. When updating a mod, remove its previous ZIP first.

Also includes a compatibility patch for ModList by its original author, obfy.
