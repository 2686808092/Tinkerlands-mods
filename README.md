# Tinkerlands Mods

**简体中文** · [English](README.en.md)

本仓库仅提供 Tinkerlands 模组总览与分发链接。各模组的源码、更新与安装包由对应独立仓库维护。

| 模组 | 功能 | 下载 |
| --- | --- | --- |
| [Just Enough Items for Tinkerlands](https://github.com/2686808092/TinkerlandsJustEnoughItems) | 在人物物品栏中搜索物品，查询配方、用途和获取途径。 | [发布与下载](https://github.com/2686808092/TinkerlandsJustEnoughItems/releases/latest) |
| [术思染的生活质量更新](https://github.com/2686808092/TinkerlandsQualityOfLife) | 合并更好的重铸、替换渔夫家具为桌子、NPC送礼简化、地图自动探索、可移动路标及更好的视觉效果；各项独立开关。仅支持已验证的独立 Playtest 单人。 | [发布与下载](https://github.com/2686808092/TinkerlandsQualityOfLife/releases/tag/v1.0.0) |
| [ModList 兼容修复（原作者 obfy）](https://github.com/2686808092/TinkerlandsModList) | 修复新版 Playtest 字体报错，保留原有 Mod 管理功能。 | [1.4.1 下载](https://github.com/2686808092/TinkerlandsModList/releases/latest) |

下载 ZIP 后，将整个压缩包放入 Tinkerlands 安装目录中的 `mods` 文件夹，再启动游戏。更新时移除同一模组的旧版 ZIP。
