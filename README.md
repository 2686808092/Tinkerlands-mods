# Tinkerlands Mods

**简体中文** · [English](README.en.md)

本仓库仅提供 Tinkerlands 模组总览与分发链接。各模组的源码、更新与安装包由对应独立仓库维护。

| 模组 | 功能 | 下载 |
| --- | --- | --- |
| [Just Enough Items for Tinkerlands](https://github.com/2686808092/TinkerlandsJustEnoughItems) | 在人物物品栏中搜索物品，查询配方、用途和获取途径。 | [发布与下载](https://github.com/2686808092/TinkerlandsJustEnoughItems/releases/latest) |
| [渔夫家具更改为桌子](https://github.com/2686808092/TinkerlandsFishermanTable) | 将渔夫入住所需的「大桌子」改为「桌子」。 | [发布与下载](https://github.com/2686808092/TinkerlandsFishermanTable/releases/latest) |
| [自动重铸](https://github.com/2686808092/TinkerlandsAutoReforge) | 在铁匠的重铸界面自动尝试重铸，命中选定的目标词缀后停止。 | [发布与下载](https://github.com/2686808092/TinkerlandsAutoReforge/releases/latest) |
| [五个礼物满好感度](https://github.com/2686808092/TinkerlandsFiveGiftAmity) | 拥有好感系统的 NPC，从零好感起送五次礼即可达到上限。 | [发布与下载](https://github.com/2686808092/TinkerlandsFiveGiftAmity/releases/latest) |
| [地图自动探索](https://github.com/2686808092/TinkerlandsMapAutoExplore) | 进入世界或切换区域时，自动揭开当前区域的地图迷雾，并把探索进度同步到原版存档。 | [发布与下载](https://github.com/2686808092/TinkerlandsMapAutoExplore/releases/latest) |
| [夜视](https://github.com/2686808092/TinkerlandsNightVision) | 提亮夜间、洞穴等暗处。默认开启，可用小地图旁的眼睛图标切换。 | [发布与下载](https://github.com/2686808092/TinkerlandsNightVision/releases/latest) |
| [ModList 兼容修复（原作者 obfy）](https://github.com/2686808092/TinkerlandsModList) | 修复新版 Playtest 字体报错，保留原有 Mod 管理功能。 | [1.4.1 下载](https://github.com/2686808092/TinkerlandsModList/releases/latest) |

下载 ZIP 后，将整个压缩包放入 Tinkerlands 安装目录中的 `mods` 文件夹，再启动游戏。更新时移除同一模组的旧版 ZIP。
